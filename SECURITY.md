# Security

Download from this repository's Releases and verify matching SHA-256 values. Checksums detect file changes; they do not independently authenticate a publisher.

This experimental installer is ad hoc signed and not notarized. Do not disable global macOS protections. Upstream dependencies retain their own maintenance policies.

Do not post credentials, sensitive logs or exploit details publicly. Use GitHub's private vulnerability reporting if available; otherwise request a private contact through a minimal issue. No response timeframe is promised.
